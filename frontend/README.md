# Todo App - Frontend

A modern and responsive frontend for the Todo application, built with **React**, **Vite**, **TypeScript**, and **Tailwind CSS**.

## Tech Stack
* **Framework:** React (with Vite)
* **Language:** TypeScript
* **Styling:** Tailwind CSS (v4)
* **Communication:** Axios/Fetch API connected to a Spring Boot backend

---

##  Getting Started (Locally)

Follow these steps to run the frontend application locally on your machine:

### 1. Prerequisites
Make sure you have [Node.js](https://nodejs.org/) installed.

### 2. Install Dependencies
Navigate to the frontend folder in your terminal and run:
